# frederikcreemers.be

This site uses Hugo **0.169.0** and the local `frederik` theme.
Install this version from the [Hugo releases](https://github.com/gohugoio/hugo/releases/tag/v0.169.0).

Preview the site with `hugo server`. Build it with `hugo`.
The repository tracks the generated `public/` directory, so rebuild and commit
the generated files alongside source changes. Do not use `--cleanDestinationDir`:
`public/` also contains standalone pages that are not generated by Hugo.

The GitLab Pages configuration uses the same pinned Hugo version.
